# 一、做菜核心经验

## 1. 放盐时机
盐会加速食材出水、影响蛋白质凝固，不同食材需选择合适的放盐时间。

| 食材类型    | 放盐时机                               | 目的                               |
| ----------- | -------------------------------------- | ---------------------------------- |
| 肉片类      | 腌制时加入各类调料并放入适量盐         | 便于入味、锁住口感                 |
| 根茎/豆制品 | 炒至七成熟放盐                         | 入味且不大量出水                   |
| 炒青菜      | 出锅前放盐                             | 保持脆嫩、不出水、不软烂           |
| 炖汤        | 临出锅前放盐                           | 避免蛋白质凝固、肉质发柴、汤色浑浊 |
| 炖菜        | 分两次放盐（一半调味、一半收汁提鲜）   | 层次更丰富                         |

## 2. 葱姜蒜 & 辣椒使用技巧
- 葱姜：去腥，宜小火煸炒；葱花建议出锅后放，起点缀作用
- 蒜：解腻
- 干椒：煸香；鲜椒：快炒
- 青红椒搭配：先放红椒，后放青椒

## 3. 常用调料区别及作用
- 炒菜：味极鲜
- 拌菜：生抽
- 上色：老抽
- 炒拌通用：蚝油

# 二、主食类

## 1. 高压锅煮稀饭
1. 按人数配比：3人2杯米（5人3杯米）
2. 加水：加开水至最高刻度线
3. 启动：调至煮饭档位后按开始
4. 关火时机：倒计时剩余10分钟时关火
5. 如加绿豆：多煮一分钟（倒计时剩9分钟时关火）

# 三、家常菜谱

> 说明：后续新增菜品，添加到对应二级分类（爆炒类 / 凉拌类 / 水煮类 / 红烧&黄焖类 / 蒜蓉类 / 干锅类）下，使用三级标题 `### x.x 菜名`；
> 如果是全新菜品大类，则新增二级标题 `## N. 新分类名称`。

## 1. 爆炒类

### 1.1 木耳韭菜炒肉片
**食材**：木耳、韭菜、青椒、适量五花肉

**步骤**：
1. 备菜：木耳用水泡开去根，控水后加盐揉搓洗净备用；韭菜洗净切长段
2. 炒肉片：五花肉切薄片，锅热后放少油煸炒肉片出油，加入葱姜、花椒、豆瓣酱小火煸炒，放青椒稍炒，盛出青椒肉片，锅中留油
3. 爆炒木耳调味：木耳下锅盖盖炸香，倒入青椒肉片，放盐和味极鲜调料、蒜末，最后加入韭菜起锅

## 2. 凉拌类

### 2.1 万能凉拌汁
**基础底料**：辣椒面、葱花、蒜末、小米辣（可加芝麻），淋热油激香

**调味配比**：2勺生抽、2勺醋，少许白糖提鲜，加食盐、蚝油搅匀

## 3. 水煮类

### 3.1 水煮肉片&水煮毛血旺&水煮双肉片
1. 煮汤：葱姜蒜花椒小火煸炒，可加辣椒面，加入豆瓣酱炒出红油，加水和盐煮出味（水量充足，建议用盛菜盆量水）
2. 腌肉片：肉切薄片，加盐和鸡蛋抓匀，淀粉水化开后拌匀，最后加油包裹锁水
3. 煮配菜及肉片：捞出佐料渣后放生抽和鸡精，先下难熟配菜，后下青菜，捞出盛盆，最后下腌肉片，筷子拨散防粘，煮熟连汤倒入盆中
4. 激香：盆中放葱花、蒜末、花椒和干辣椒，淋热油激香

## 4. 红烧&黄焖类

### 4.1 黄焖鸡爪
1. 焯水：鸡爪剪指甲、泡水半小时，冷水下锅加姜料酒焯水去腥，捞出加老抽上色
2. 油炸：七成热油炸3分钟，捞出备用
3. 黄焖：葱姜、桂皮、八角、香叶、豆瓣酱小火炒出红油，放鸡爪，加老抽、味极鲜、半瓶啤酒、一碗清水，放泡好花生米，焖15分钟
4. 收汁：汤汁多时大火收汁，挑出葱姜

### 4.2 红烧金鲳鱼
**食材**：金鲳鱼1条、生姜、大葱、大蒜、干辣椒少许、花椒、生抽2勺、老抽半勺、料酒2勺、白糖1小勺、盐少许、适量开水

**步骤**：
1. 鱼处理干净，两面划2‑3刀，使用**厨房纸彻底吸干鱼身表面水分**；鱼身抹少许盐+1勺料酒，铺上姜片腌制10分钟，腌好后**再次擦干鱼表面水分**，防止煎鱼破皮溅油。
2. **锅烧热再倒入食用油**，中小火将鱼下锅，一面煎至金黄定型之后再翻面，两面煎好盛出备用。
3. 锅内留底油，下入葱姜蒜、花椒、干辣椒**小火煸炒，不要炒糊**，炒出香料香味。
4. 依次倒入料酒、生抽、老抽、白糖简单翻炒，加入**开水**，水量只需要没过鱼身一半即可。
5. 将煎好的鱼放回锅中，大火烧开转中小火焖8‑10分钟，焖煮过程中**不断用勺子舀汤汁淋在鱼身上帮助入味**。
6. 开盖尝咸淡，按需补盐，大火收浓汤汁，汤汁发亮即可关火，撒葱花出锅。

> 💡重点注意：
> - **一定要加开水，冷水会让鱼肉收缩变柴**；
> - 老抽仅用来上色，**不要多放，避免成品发黑**；
> - 金鲳鱼肉厚，焖煮时间不宜过久，防止肉质变老。

## 5. 蒜蓉类

### 5.1 万能金银蒜蓉酱
1. 五成热油倒入一半蒜泥，炒至金黄关火
2. 加入另一半蒜泥、打碎小米辣、2勺生抽、1勺蚝油、半勺白糖
3. 再次开火炒香

### 5.2 蒜蓉油焖基围虾
1. 基围虾去虾线、开背，煎至金黄盛出
2. 五成热油爆香蒜末、小米辣，倒入煎虾
3. 2勺生抽、1勺蚝油、半勺白糖和鸡精加盐兑水，倒锅中焖2分钟
4. 出锅撒葱花

💡 技巧：去虾胃和虾线——从头处沿虾胃处剪斜口，轻挤虾胃并慢慢拔出虾线
