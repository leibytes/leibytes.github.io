# Tampermonkey（油猴/篡改猴）完整安装及使用教程
> 核心概念：\*\*Tampermonkey 只是扩展（脚本运行容器），本身没有功能；真正实现功能的是用户脚本（js 代码）\*\*。
>
## 一、安装 Tampermonkey（篡改猴）扩展
### 方式 1：Chrome 浏览器
1. 国内无法访问谷歌网上应用店，无法直接搜索到Tampermonkey扩展程序。
2. 替代方案：可通过github下载油猴压缩包后拖到浏览器的扩展程序面板，github下载地址：。
> ⚠️ \*\*重要提示\*\*：不建议网上随便下载 crx 离线包，容易植入恶意代码。
### 方式 2：Microsoft Edge 浏览器（推荐，零网络问题Windows 自带）
1. 浏览器右上角「⋯」菜单 → \*\*扩展\*\* → \*\*获取 Microsoft Edge 扩展\*\*
2. 搜索：`Tampermonkey`，中文叫\*\*篡改猴\*\*，认准官方图标（两个小方块），点【获取】→【添加扩展】
3. 安装完成，点击扩展图标，点\*\*固定到工具栏\*\*，图标就常驻浏览器右上角。
4. 点开篡改猴图标 → \*\*管理面板（仪表盘）\*\*，进入脚本管理界面。
## 二、两种安装脚本的方式
### 方式 A：手动粘贴代码（就是我们网课脚本用的方式，最安全）
1. 点击右上角 Tampermonkey 图标 → \*\*添加新脚本\*\*（\+ 号按钮）
2. 编辑器会自带模板，\*\*把全部默认内容全部删除\*\*
3. 把完整脚本代码粘贴进去（包含头部`// ==UserScript==`元信息，不能删掉）
4. 快捷键 `Ctrl + S` 保存脚本。
5. 在管理面板列表看到脚本，勾选代表\*\*启用\*\*。
### 方式 B：在线脚本库安装现成脚本（Greasy Fork）
Greasy Fork 是全球最大油猴脚本开源社区，大量别人写好的脚本。
1. 打开网站：Greasy Fork
2. 搜索想要的功能，例如：解除复制限制、网页去广告、视频增强
3. 进入脚本详情页，点击绿色按钮 \*\*安装此脚本\*\*
4. Tampermonkey 会弹出预览窗口，点击【安装】完成。
> ⚠安全提醒：第三方脚本权限很高，可以读取网页账号信息，不要随意安装来路不明脚本，尽量看脚本源码、评论再安装。
>
>
## 三、常用操作（管理面板）
打开 Tampermonkey「管理面板」：
1. ✅勾选：启用脚本；取消勾选：临时禁用脚本，不用删除。
2. 点击脚本名称：进入编辑器，可以修改源码，改完`Ctrl+S`立刻生效，\*\*页面刷新就会执行新代码\*\*。
3. 删除：不需要脚本直接移除。
4. 实用工具：支持脚本备份导出，更换浏览器可以导入。
## 四、脚本头部元注释含义（非常重要，不能乱删）
```javascript
// ==UserScript==
// @name 脚本名称
// @namespace http://tampermonkey.net/
// @version 1.4
// @description 功能描述
// @author 作者
// @match \*://\*.cup.com.cn/\* // 匹配哪些网址运行脚本，\*代表通配符
// @grant none // GM\_\*高级API权限，none代表只用普通网页JS
// @run-at document-idle // 网页加载完毕后注入脚本
// ==/UserScript==
```
- `@match`：控制脚本在哪个网站运行；写错网址脚本完全不会执行。
- `@grant`：需要剪贴板、跨域请求等特殊能力才开启 GM 权限；普通网页自动化写`none`。
## 五、调试排错方法（你网课脚本经常会用到）
1. \*\*脚本不生效\*\*
- 确认脚本前面勾选启用；
- 检查`@match`网址是否匹配当前网页；
- 网页按`F5`强制刷新页面；
2. \*\*查看报错日志\*\*
网页按`F12`打开开发者工具 → \*\*Console \(控制台\)\*\*，可以看到脚本报错信息。
- `NotAllowedError`：浏览器安全限制，典型就是无交互不能自动播放视频。
3. \*\*会话存储查看\*\*
F12 → Application → Session Storage，可以查看脚本保存的临时数据（你的网课脚本`next\_learn\_index`下标在这里查看）。
## 六、常见限制（浏览器底层，脚本绕不开）
1. \*\*自动播放限制\*\*：页面必须有一次人为点击交互，脚本才能调用视频 play \(\)；刚打开页面无任何点击，会被浏览器拦截播放。
2. \*\*页面休眠节流\*\*：标签页切后台最小化，浏览器会降低定时器频率，脚本运行变慢甚至暂停，\*\*标签页尽量保持前台\*\*。
3. \*\*网站改版脚本失效\*\*：网站更新 DOM class 名称（比如`courseCard`改名），脚本选择器失效，需要修改代码适配。
4. \*\*网站风控\*\*：高倍速、高频自动化操作，平台后台可能识别异常，造成学时不记录。
## 七、油猴脚本可以做什么（场景汇总）
1. ✅网页自动化：网课自动连播、自动签到、批量点击、表单自动填充（你的场景）
2. ✅网页增强：解除禁止复制、移除弹窗广告、视频自定义倍速
3. ✅界面美化：修改网页样式、暗色模式、精简页面
4. ✅开发调试：临时修改网页逻辑，测试前端效果
## ⚠安全红线
1. 第三方脚本谨慎安装，优先自己手写脚本；
2. 不要用来破解、绕过平台协议做违规操作；
3. 不要在不知名网站下载所谓油猴 crx 离线包，有窃取账号风险。
