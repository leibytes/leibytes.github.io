# Markdown 符号速查表及模板
## 一、标题符号
```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```
## 二、文字格式
```markdown
\*单星号斜体\*
\*\*双星号加粗\*\*
\*\*\*三型号加粗斜体\*\*\*
~~删除线~~
下划线
```
## 三、列表符号
无序列表：
```markdown
- 列表项
\* 列表项
+ 列表项
```
\*\*例如：\*\*
- Nginx 先看请求是 \*\*80 / 443\*\* 等端口
- 找到所有监听该端口的 `server` 块
- 不在该端口的 server \*\*直接排除\*\*
有序列表：
```markdown
1. 第一项
2. 第二项
3. 第三项
```
## 四、引用符号
```markdown
> 一级引用
>> 二级引用
>>> 三级引用
```
## 五、代码相关
单引号包裹行内代码：
```markdown
`代码内容`
```
三引号后面跟具体的语言包裹代码块：
````markdown
```java
代码块内容
```
````
\*\*注意：代码块内部的#号原始展示，代表注释不再是标题\*\*
## 六、链接与图片
链接：
```markdown
[显示文字](网址)
```
图片：
```markdown
![图片说明](图片地址)
```
## 七、分割线
```markdown
---或者\*\*\*
```
